The app is an MCP server for external AI assistants (ChatGPT, Claude, Cursor).

- Authoring surface: `src/lib/mcp/index.ts` (`defineMcp`) + one tool per file in `src/lib/mcp/tools/`. `supabase/functions/mcp/index.ts` is auto-generated by `mcpPlugin()` in vite.config.ts — never hand-edit it.
- Auth: Supabase OAuth 2.1 resource server. Issuer built from `VITE_SUPABASE_PROJECT_ID` (`https://<ref>.supabase.co/auth/v1`), audience `authenticated`. Tools forward the caller's token so RLS runs as that user.
- Consent page: `/.lovable/oauth/consent` → `src/pages/OAuthConsent.tsx` (pt-BR). `/auth` honors a validated same-origin `?next=` for password login, signup `emailRedirectTo`, and Google `redirect_uri`.
- Tools: `list_events`, `get_event_stats`, `list_registrations`, `check_in_registration`.
- After any MCP change: run manifest extraction and redeploy the `mcp` edge function.
